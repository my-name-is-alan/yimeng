# 平台账号隔离与固定共享取流

2026-10-23 · 已实现 · schema 28 · API 1.4

## 使用方法

1. 管理员在「设置 → 音源插件」启用网易云等平台，并登录自己的平台账号。
2. 打开该平台的「账号」列表，选择具体账号的「授权取流」，选择成员、填写共享来源名称并确认。
3. 成员登录自己的译梦账号，在同一设置页登录自己的网易云账号；收藏、歌单、每日推荐、私人 FM 和反馈使用其个人账号。
4. 成员在「播放来源与共享授权」查看获授来源。播放固定使用授权指定账号，不因管理员切换个人默认账号而改变。
5. 管理员可以撤销授权。新请求、已有 lease、签名 URL、HEAD、Range、下载和 Subsonic 都重新校验授权；正在传输的音频会被取消。

未授权、授权撤销、出借账号需要重新登录、平台停用均返回明确错误，不回退到成员自己的账号、其他管理员账号、本地等价曲目或其他平台。管理员自己的播放使用自己的默认平台账号。原有自动换源偏好不参与此模式。

共享仅授予取流，不开放出借者的收藏、推荐、歌单、历史和凭据。平台实际返回不可播或试听时仍按其权益处理，不破解 DRM。平台可能通过取流请求更新出借账号画像；Core 不会主动把成员的反馈写入出借账号，但无法保证平台侧完全不受影响。

## 实现边界

- 登录用户来自认证中间件的 `owner` 上下文，不接受请求体指定数据所属用户。
- 个人平台 Registry 按译梦用户隔离；Cookie jar、平台实例、个人默认账号和账号列表不再服务器级共用。
- 保留原 `/plugins/...` 登录与账号接口路径，但它们现在仅管理当前用户自己的账号。普通成员可以管理自己，服务器级启用和插件配置仍仅限管理员。
- 平台会话与共享授权管理不允许 API key 调用，必须使用用户登录会话。播放用 API key、签名 URL 和 Subsonic 凭据时仍验证归属与授权。
- 同一用户的个人平台请求序列化；切换身份前等待其缓存后台刷新结束。不同用户可以并发，不能用临时修改全局默认账号的方式切换身份。
- 流请求使用独立的、绑定具体出借账号会话的运行实例，不持有整段播放期间的个人账号锁；同一出借账号的取流实例共享限流与风控状态。
- 委托流会话与当前个人默认账号分离。删除/重新登录出借账号会失效旧会话；切换到另一个默认账号不会中断原账号的授权。
- WS/SSE 的个人平台状态事件按用户投递。公共服务器信息使用无登录状态实例，携带有效认证时只展示该用户自己的账号详情。
- 听歌识曲使用自己的网易云会话，不借用 `stream` 授权。旧 Apple StreamSource 占位接口仍为管理员接口，不作为共享取流入口。
- NAS 本地曲库仍为服务器公共曲库。个人收藏与平台账号隔离不等于按用户隐藏 NAS 文件目录。
- 隔离是 Core API 的访问控制，不是防止拥有 NAS 数据库、主密钥或进程控制权的人读取数据的加密多租户方案。

## 存储与迁移

新增 `0028_online_isolation.sql`，不修改旧迁移。

- `online_owner_state`：用户对应的不可碰撞命名空间与个人缓存代次。
- 既有 `plugin_accounts`：内部 `plugin_id` 增加用户命名空间；对外平台 ID 不变。账号 ID 沿用平台账号 ID，所有查询必须先经过用户命名空间限定，不把 ID 当作权限。
- `online_secret_refs`：用户与 Vault 存储引用。Vault key 对用户和逻辑键做哈希，维持既有长度上限；凭据继续用 AES-GCM 加密。
- `stream_grants`：授予者、受让成员、平台、具体账号、展示名称、版本和撤销状态。每个成员/平台最多一个固定授权；管理员不能覆盖另一位管理员的授权。
- `online_config_version`：服务器配置代次，防止配置变化或重启后重用旧缓存。
- `online_legacy_migration` / `online_legacy_cleanup`：可重试的旧账号归属和旧密钥清理记录。
- 删除用户时，触发器清理个人 Vault 引用与对应密文、账号记录和个人缓存，授权外键级联清理。活跃流还周期性检查用户存在性与角色变化。

升级时先走现有的迁移前备份。唯一管理员环境自动归属旧账号；多管理员环境不猜测，旧账号隔离保存，由原所有者在设置中确认认领。旧凭据复制并验证后才提交归属；提交后按持久化清理队列删除旧凭据，清理中断可在重启后重试。

只有活动凭据、没有多账号列表的旧版本，会恢复为名为「迁移账号」的个人账号槽位。迁移不创建共享授权，因此成员必须等待管理员显式授权后才能在线播放。

## 缓存和撤销

- 当前实现保守地把平台目录缓存也按用户/会话代次隔离，而非立即拆出所有公共 DTO；公共图片缓存沿用现有规则。
- 私人歌单、推荐、single-flight、SWR 刷新都使用所属用户的缓存空间，退出或换号后不能命中旧身份缓存。
- 取流 lease 键包含听歌用户、出借者、具体平台账号、会话标识、授权 ID/版本、曲目和音质。内存 lease 与实例池有上限。
- 会话标识是内部凭据摘要，不返回客户端；客户端只得到 Core 的串流 URL，不得到平台 Cookie 或上游完整流 URL。
- 旧的全局 `external_status` 和目录中的个人权益提示不再充当成员播放权益的权威数据；实际解析出借账号取流后确定完整、试听或不可播状态。
- 每次缓存命中前检查账号与授权，代理取流前再次验证并登记取消句柄。授权撤销即时取消对应句柄；用户删除、降级等外部变化由周期检查补充发现。
- 已经发送给客户端的字节不能追回，不宣称撤销能删除客户端已保存的内容。

## API

OpenAPI 位于 `api/openapi.yaml`，共享 DTO 位于 `packages/shared/src/api.ts`。

- `GET /api/v1/me/platform-bindings`：当前用户的播放模式和授权。成员响应不含出借者账号 ID、用户 ID 或私人资料。
- `GET /api/v1/admin/stream-grants`：列出当前管理员发出的授权。
- `POST /api/v1/admin/stream-grants`：`consumer_user_id`、`platform`、`account_id`、可选 `label`；仅允许出借自己的保存账号。
- `DELETE /api/v1/admin/stream-grants/{grant}`：撤销本人发出的授权。
- `POST /api/v1/admin/platform-legacy/claim`：确认把未归属旧账号迁移到当前管理员。
- `/api/v1/plugins/{id}/login`、`login/qr`、`login/sms`、`refresh`、`session`、`accounts`：个人账号管理；QR challenge 校验创建者和有效期。

`available` 表示本地授权、账号与保存会话具备使用条件，不保证上游平台当前在线。主要错误：`shared_stream_required`、`shared_stream_revoked`、`shared_account_needs_login`、`plugin_disabled`、`risk_control`。共享账号失效不会误退出成员的译梦登录。

## 设置与浏览器状态

- 成员可登录、刷新、退出、添加和切换自己的平台账号，但看不到管理员的账号列表或授权管理按钮。
- 管理员从具体账号行授予取流，在「播放来源与共享授权」查看和撤销。
- 设置页新增退出译梦账号入口，移动端账号操作会自动换行。
- Web 播放队列按译梦用户保存；换号停止旧音频与预取，清除当前歌词、权益和在途加载身份。不把旧版本无归属队列自动分配给新登录用户。
- 其他标签页改变登录令牌时，本页停止旧会话并重新加载。
